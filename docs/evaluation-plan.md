# Evaluation plan

## Offline quality

- Formula and scenario-unit tests
- Source freshness and citation coverage
- Range calibration on historical holdouts
- Counterfactual consistency when one input changes
- Safety-policy and prohibited-use tests

## Human evaluation

- Financial-counselor review
- First-time-buyer comprehension testing
- Accessibility review
- Red-team testing for steering, overconfidence, and privacy leakage

## Pilot metrics

- Planning completion rate
- Assumption-correction rate
- Scenario comparison usage
- Explanation comprehension
- Human-handoff acceptance
- Material error and complaint rate
- Outcome gaps across monitored groups

## Launch gate

Do not launch solely because engagement improves. Require acceptable calculation accuracy, user comprehension, accessibility, privacy controls, fairness review, and a staffed escalation process.
